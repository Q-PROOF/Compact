# AGENTS.md — compactq contributor guide

## Project overview

compactq is a zero-dependency quantum circuit optimizer. It takes a quantum circuit
and returns an equivalent one with fewer gates and shallower depth. Every output
is mathematically verified before being returned.

## Architecture

```
compactq/
├── circuit.py      # Circuit/Gate IR (frozen dataclasses, validated)
├── linalg.py       # 2x2 complex matrix algebra + Euler decomposition
├── transforms.py   # optimization passes (peephole, slide, cancel, swap)
├── cp_pass.py      # CX-pair cancellation through diagonals → CP gates
├── optimize.py     # optimize() [safe] and optimize_deep() [KAK cascade]
├── search.py       # optimize_search() — best of {safe, deep}
├── equivalence.py  # full-unitary equivalence proof (8 qubits w/ native kernels)
├── verify_large.py # randomized K-state verification (~30 qubits, numpy optional)
├── kak.py          # 2-qubit block consolidation + re-synthesis (pure-Python Weyl)
├── stabilizer.py   # Clifford tableaux (AG) + tableau-proven equality
├── clifford.py     # Clifford block resynthesis
├── cliffordt.py    # Clifford+T normal form
├── parity.py       # phase-polynomial / parity-network resynthesis
├── target.py       # hardware Target objectives, native CZ/ECR/iSWAP rebase
├── approximate.py  # bounded-fidelity approximate mode
├── hardware.py     # routing (SABRE-lite), direction flip, exact placement
├── symbolic.py     # parameterized circuits (structure once, bind later)
├── mcx.py          # mcx/mcp parity-network expansion
├── io_qasm.py      # OpenQASM 2.0 import/export (+ QASM3 common-subset import)
├── io_qasm3.py     # OpenQASM 3.0 export
├── qiskit_bridge.py# Qiskit interop + transpiler plugin (optional)
├── cirq_bridge.py  # Cirq export (optional)
├── noise.py        # NoiseModel (T1/T2, gate infidelity, readout, drift)
├── suppress.py     # twirling + benefit-gated DD + one-call suppression
├── mitigate.py     # tensored readout mitigation + MLE
├── zne.py, cdr.py  # zero-noise extrapolation, Clifford data regression
├── simulate.py     # zero-dep trajectory noise simulator (n<=14)
├── stabsim.py      # CHP stabilizer simulator (n~60)
├── shadows.py      # classical shadows
├── metrics.py      # layer fidelity / EPLG
├── resources.py    # T-count / T-depth, Clifford+T rebase
├── solvers.py      # MaxCut-QAOA
├── interfaces.py   # stim export, optional QCEC referee
├── adapters.py     # qiskit-runtime / Braket execution adapters
├── benchmarks.py   # standard benchmark circuits
├── bench.py        # benchmark CLI (compactq vs Qiskit when installed)
└── native/         # optional Rust kernels (PyO3; Windows wheels prebuilt)
```

## Key invariants (do not break these)

1. **Exactness**: every rewrite preserves the unitary up to global phase
2. **Verification net**: `optimize()` proves results within the dense proof limit (8q with the native kernels), `optimize_large()` adds randomized K-state verification beyond it,
   returning; on any doubt it returns the original unchanged
3. **Never grow**: the optimizer never increases the chosen objective
   lexicographically — default `2q` order (2q count, total, depth); also
   `depth` and `gate_count` orders via the `objective=` parameter (each is
   a reordering of the same tuple, so the invariant holds by construction);
   `weighted` mode guarantees the weighted cost never increases
4. **Zero dependencies**: the core (`compactq/`) uses only Python stdlib
5. **Property tests**: every pass must survive 500+ random-circuit trials

## Running tests

```bash
python tests/run_tests.py          # zero-dep test runner
python -m pytest compactq/tests/       # pytest (if installed)
python -m compactq.bench --quick      # quick benchmark regression guard
```

## Code style

- Type hints: `from __future__ import annotations` + inline hints
- Docstrings: every public function
- Error handling: pass silently falls back on numerical doubt, never crashes
- Naming: `snake_case` for functions, `PascalCase` for classes
- Gate representation: frozen `Gate(name, params, qubits)` dataclass

## Adding a new optimization pass

1. Write the pass as `fn(circ: Circuit) -> Circuit`
2. Every rewrite must be exact (test with random-circuit property tests)
3. Add the pass to the `optimize()` pipeline (between existing passes)
4. Add the pass to the fixpoint loop (iterate until no improvement)
5. Run `python tests/run_tests.py` — all must pass
6. Run `python -m compactq.bench --quick` — no regressions
7. Add unit tests for the new pass

## Benchmark protocol

All comparisons use the same protocol:
- Identical input circuit (same QASM, same translation)
- Same target basis set
- Fixed seeds
- Best-of-3 wall-clock timings
- qiskit 2.5+ with `optimization_level=3`

Results are generated by `python -m compactq.bench` and stored in the README.
Never report a benchmark without re-running it.

## Adding a new gate to the IR

1. Add name to `ONE_Q_GATES` or `TWO_Q_GATES` in `circuit.py`
2. Add matrix to `NAMED_MATRICES` or `gate_matrix()` in `linalg.py`
3. Add phase angle to `_PHASE_OF` if diagonal (for `diag_slide`)
4. Add to `to_qasm()` and `from_qasm()` in `io_qasm.py`
5. Add to `to_qasm3()` in `io_qasm3.py`
6. Add to qiskit_bridge whitelist in `qiskit_bridge.py`
7. Add to cirq_bridge in `cirq_bridge.py`
8. Verify with property tests

## Known limitations

- Dense verification to 8 qubits (6 pure-Python); randomized K-state
  verification beyond (numpy optional, ~30q practical ceiling)
- Unitary-core scope: mid-circuit measurement / reset / classical control
  flow are rejected with `UnsupportedCircuitError`, never silently dropped
- Raw compile speed on large circuits trails Qiskit's Rust pass engine;
  the optional `native/` kernels ship as Windows wheels today — other
  platforms build from source with maturin (silent pure-Python fallback)
- Suppression-stack evidence is simulator-based; hardware-backed
  benchmarks pending (execution adapters shipped)
