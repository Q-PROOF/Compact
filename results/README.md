# Benchmark artifacts

Raw, machine-readable results behind every measured claim in the README.
No claim without a producer script; no number without a raw artifact.

**One-command regeneration (v0.2.4):** `python scripts/run_benchmarks.py`
runs the repro + DD-ceiling + latency families in sequence.  The suite is
pinned by [`MANIFEST.json`](MANIFEST.json) — per-circuit QASM digests
plus referee/tool versions; any environment drift aborts loudly instead
of producing incomparable numbers (re-pin deliberately with
`scripts/repro_harness.py --update-manifest`).

## Layout

| artifact | producer | contents |
|---|---|---|
| `MANIFEST.json` | `python scripts/repro_harness.py` (auto-written / `--update-manifest`) | **the suite pin**: per-circuit qubits/depth/QASM sha256 (raw + u3+cx-lowered), referee version pinned, protocol, tool list |
| `../bench_results.json` | `python scripts/bench_json.py` | per-circuit QASMBench small: Compact vs Qiskit L3, gates/2q/depth, wall time, referee fidelity, proof status, tool versions, commit SHA, machine info |
| `../bench_results.md` | generated by the same run (never hand-edited) | human summary of the above |
| `../head_to_head_results.json` | `python scripts/head_to_head.py` | raw vs qiskit-O3 vs qiskit-O3+suppression vs compact-full, per scenario |
| `../suppress_results.json` | `python scripts/suppress_bench.py` | suppression pipeline vs raw execution, per scenario |
| `../dd_sequence_results.json` | `python scripts/suppress_bench.py` | DD sequence family comparison (xy4/xy8/xzx/pdd4/auto) |
| `../scale_results.json` | `python scripts/scale_bench.py` | CHP stabilizer simulator scaling (n=16..24) |
| `scalability.json` + `scalability.md` | `python scripts/scale_gauntlet.py` | per-width correctness/stability/runtime/memory ceilings, 4 → 256 qubits × 8 workload families, tiered verification (independent Qiskit referee / algebraic tableau at any width / never-grow policy + determinism) |
| `repro.json` + `repro.csv` + `repro.md` | `python scripts/repro_harness.py` | same-input, same-gate-set comparison: Compact vs Qiskit L3 vs pytket vs Cirq on independently generated circuits, every output lowered to u3+cx and refereed (CSV added v0.2.4) |
| `dd_ceiling.json` + `dd_ceiling.md` | `python scripts/dd_ceiling_bench.py` | **v0.2.4**: DD-prover structured-circuit proof ceiling per family (QFT/Trotter/GHZ/Grover-MCX): nodes, wall time, proven widths, self-consistency status + v0.2.3 before/after deltas |
| `mqtbench.json` + `mqtbench.md` | `python scripts/mqtbench_run.py` | MQT Bench algorithm-level circuits, four-way (compact/qiskit L3/pytket/cirq), referee fidelity ≤ 8q |
| `feynman.json` + `feynman.md` | `python scripts/feynman_bench.py` | **v0.2.4**: meamy/feynman `benchmarks/qasm` corpus (44 reversible / Clifford+T circuits) — verified optimization with per-circuit proof tier and T-counts |
| `benchpress/` | `python scripts/benchpress_run.py --gym compactq` (+ `--gym qiskit`) | **v0.2.4**: Qiskit Benchpress abstract-transpile workout, QASMBench at all-to-all, native pytest-benchmark records; gym adapter in `benchpress_integration/` |
| `SCORECARD.json` + `SCORECARD.md` | `python scripts/scorecard.py` | **v0.2.4**: the multi-metric scorecard aggregating every corpus (median/geomean reductions, entangling reduction, compile p50/p95, verified/total, dispositions) |
| `pytket_referee.json` | `python scripts/referee_pytket.py` | per-circuit referee records for pytket default + safe modes: version, mode, output fidelity, status, metrics — the raw evidence behind the inequivalence claims |
| `bqskit.json` | `python scripts/bqskit_bench.py` | **BQSKit 1.2.1 measured head-to-head** (documented `bqskit.compile` pipeline): per-circuit gates/2q/CX-equivalent/depth/fidelity/status on the QASMBench small suite |
| `../volumetric_report.md` | `python scripts/volumetric_report.py` | QED-C-style width/depth tables |
| `environment.json` | maintained by hand, reviewed in PRs | exact software/hardware environment + commands + protocol |
| `../COMPARISON.md` | `python scripts/gen_comparison.py` | **v0.2.4**: the competitor matrix generated from the artifacts above, every row labeled [measured] / [referee] / [literature] / [not runnable here] |
